## 🌳 Overview  
The Enchanted Grove transforms studying from a stressful, lonely task into a magical journey.  
Inside the grove, learners face AI‑generated trials, earn light, and support each other through enchanted messages.

This project blends:
- AI  
- Gamification  
- Emotional design  
- Fantasy worldbuilding  
- Beautiful animations  
- Community encouragement

## 🚀 Deployment (GitHub Pages)

### 1. Push your files to GitHub  
Make sure `index.html`, `style.css`, and `script.js` are in the root folder.

### 2. Go to  
**Settings → Pages**

### 3. Select  
- Branch: `main`  
- Folder: `/root`

### 4. Save  
Your site will be live at:  
`https://<username>.github.io/<repo-name>/`
